# duoalley.com (a redirect)

The game was called Duo Alley until 2026-10-27; it is now Hinge Alley, and its site is
https://hingealley.com (repository `therealcreynold/hingealley-website`). This repository only keeps
the old domain working: GitHub Pages serves it at duoalley.com, and every page (and the 404 page, for any
other path) sends the visitor to the same path on hingealley.com, by script and by meta refresh.
